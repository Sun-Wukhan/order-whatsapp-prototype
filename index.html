Environment / Keys — Where Real Keys Will Plug In

Everything is wired to these variables. In the prototype they’re empty / masked and the provider is forced to MOCK. Plugging in real keys + switching mode to LIVE is the only change needed conceptually — the pages, API calls, and webhooks stay the same.

Configuration (simulated .env)

Mode is locked to MOCK. The “Go Live” switch stays disabled until all keys above are present and the webhook is verified — exactly the gate we’ll implement in production.
